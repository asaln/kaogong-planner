    📖 使用说明

    1. 打卡：任务前复选框点一下即标记完成（自动划线变灰），进度条与顶部统计实时更新。
    2. 改任务（需求2，重点）：直接点任务文字即可编辑，支持换行（手机上直接换一行写一条）；回车 = 保存并退出，Shift + 回车 = 在任务里插入换行。每条右侧的 × 可删除该条。
    3. 增任务：每天任务清单底部「＋ 新增一条任务」按钮；整天的任务可用右侧「✎」批量重写（一行一条）。
    4. 新增/删除某一天：工具栏「＋ 新增一天」，按 YYYY-MM-DD 输入日期即可；某天右侧「🗑」删除整天。
    5. 保存：以上所有修改即时自动保存。配置云端后，任何改动都会推送到云端；换手机、换电脑、换浏览器登录同一网址，打开即看到最新内容（需求1、4）。
    6. 筛选排序：顶部按阶段/类型/完成状态筛选，搜索框按日期片段检索（如 2026-11 看11月），点表头排序。
    7. 打印：点「🖨 打印」可打印当前筛选结果贴墙。
    8. 备份：「⬇ 备份」导出 JSON，「⬆ 恢复」读回。云端同步之外的第二份保险。
    9. 恢复原始任务：改乱时点「↺ 恢复原始任务」，一键还原任务清单（打卡进度、用时、备注均保留）。
    10. 部署与同步：见 README.md，把仓库 Fork 到自己的 GitHub、开启 Pages 与 Actions 后，填一个同步令牌即可实现多端互通。

    ⚙ 多端同步设置

    开启后，你在任意手机/电脑/浏览器上的打卡与任务修改都会实时上传云端，别处打开自动同步。
    这个令牌是一个你自己定的字符串（建议 20 位以上随机字符），只用于区分你是不是合法访问者，和 GitHub 账号密码无关。

    未开启同步时，所有数据仅保存在当前浏览器本地，换设备不会自动共享。

    两栏都留空 = 仅本机保存。填了之后，手机/电脑/其他浏览器登录同一网址即可共享打卡进度。
